Projektbeskrivning
I denna uppgift har jag byggt ett program som hjälper användaren att hålla koll på sina jobbansökningar.
Programmet låter användaren lägga till nya ansökningar, uppdatera statusen för befintliga ansökningar, 
ta bort ansökningar och visa en lista över alla ansökningar med deras nuvarande status.




Hur man kör programmet
När man startar programmet kommer användaren att presenteras med en meny med olika alternativ som är 
numrerade. Användaren kan välja ett alternativ genom att skriva in motsvarande nummer och trycka på Enter.
Menyval: 1. Lägg till ansökan, 2. Uppdatera ansökan, 3. Ta bort ansökan, 4. Visa alla ansökningar, 5. Avsluta programmet.
Programmet kommer sedan att utföra den valda åtgärden och återgå till menyn tills man väljer att avsluta programmet.
